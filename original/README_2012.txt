Multi-block load patch for EmuZ-80K		2012/04/14

This patch adds the feature to load multi-block tape data
such as FORM programs.

Download the source code of EmuZ-80K (3/20/2012 version) from
http://homepage3.nifty.com/takeda-toshiya/
and replace the following files:

 src\winmain.cpp
 src\vm\datarec.h
 src\vm\datarec.cpp

Executable binary module is also included for your convenience.
